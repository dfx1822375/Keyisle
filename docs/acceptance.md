# 人工验收清单

当前版本为 1.0.0 发布候选版。测试环境为 Windows x64 系统内部版本 10.0.26200。自动测试结果见 [验证记录](validation.md)；未执行的项目不能标为通过。

本轮人工体验重点：

- [ ] 主界面空白与账号行可拖动；输入、选择文字和按钮操作正常。
- [ ] 四边、四角可调整大小，双击页头标题最大化或还原，锁定再解锁后保留本次调整的主界面尺寸。
- [ ] 双击账号或 F2 编辑；删除确认期间不能直接进入编辑；更多菜单可收起或退出。
- [ ] 悬浮框右键操作定位正确账号，转入主界面执行，保留草稿保护、删除确认和敏感复验。
- [ ] 悬浮框顶部显示 Chrome / aTrust 等目标应用，目标失效时提示重新定位输入框。
- [ ] 四套浅色配色统一保存后同步两窗并保留至重启；成功提示为绿色，错误提示不会被旧成功计时器清除。
- [ ] 在实际 aTrust、多显示器和不同缩放比例下复核以上体验。

## 首次使用与密码库

- 新用户打开程序后显示创建密码库，不出现示例账号。
- 两次主密码不一致、主密码不足 10 个字符时拒绝创建。
- 新建账号，填写名称、用户名、密码、分类、多个标签、网址和多行备注；保存后编辑，核对内容。
- 搜索名称、用户名、分类及标签；密码不能被搜到。分类和标签筛选来自已保存账号。
- 点击“锁定”，确认列表和编辑表单清空；重新解锁后记录完整。重启需要再次输入主密码。
- 修改和删除前创建加密备份；删除需要再次确认。
- 手工保存一份加密备份，恢复时输入原主密码，确认产生工作副本，原库保持不变。

## 敏感项与锁定设置

- 勾选敏感项后，列表隐藏用户名；普通账号无需额外验证，敏感账号的三种填充都必须先验证。
- 错误主密码、取消验证不执行操作；验证时切换窗口或锁屏，不得继续填充。
- 每次进入敏感编辑器都要重新验证；取消敏感标记也必须先通过该编辑验证。
- 删除敏感账号先确认、再验证；取消后记录保持完整。
- 手工加密备份并恢复，核对敏感标记及验证行为保留。
- 在本机已配置 Windows Hello 时，亲自测试 PIN、指纹或人脸的成功和取消；不要在聊天中提供这些凭据。
- 主界面“设置”提供 1、5、15、30、60 分钟，以及电脑空闲或密码库空闲。保存后立即生效，重启后保留。
- 密码库空闲模式下，使用其他程序不应续期；电脑空闲模式下，键鼠活动应续期。锁屏和休眠不受这些设置影响。
- 旧版密码库升级后，确认生成升级前加密备份，记录完整，旧记录默认没有敏感标记。

## 悬浮框、筛选与窗口恢复

- 空字段或控制符报错后，不关闭悬浮框，直接搜索另一个有效账号并填入；原输入框不得收到部分用户名或密码。
- 鼠标点击其他窗口后，再点击悬浮框，确认可搜索、上下选择并填入原目标。
- 在悬浮框内再次按呼出快捷键，保留查询和选择；在另一个输入框按快捷键时，更新目标。
- 主界面连续最小化、恢复，确认背景与文字完整；也测试从托盘恢复。自动回归已读取实际客户区像素，避免 PrintWindow 影响验证。
- 组合使用分类、标签、关键词；清除筛选后，控件、条件文字和列表同时恢复。
- 修改呼出快捷键，确认立即生效并在重启后保留。遇到组合冲突时，旧快捷键继续可用；启动冲突时仍能进入设置修改。

## Windows 账户验证

- 选择敏感项，将验证方式切换为“Windows 账户密码”，点击“打开 Windows 验证”，确认密码只在系统弹窗内输入。
- 正确密码后，仅执行当前操作；取消和超时不得打开编辑器或填入字段。确认超时后没有遗留验证进程。
- 验证其他 Windows 账户时必须拒绝；不要通过反复猜测系统密码做测试，以免触发账户锁定策略。
- 验证页打开期间锁库或锁屏，返回后不得执行原操作。
- 没有配置 Hello 时，账户密码和密码库主密码入口仍可使用。PIN、指纹或人脸的真实成功路径仅在已配置环境验收。

## Chrome

先新建一条用于验收的假账号，名称为“Chrome 测试”，再使用本项目 `test-input.html` 的本地页面，不提交登录。

- 点击密码框，按 Ctrl + Alt + P，只出现独立悬浮框；搜索并按 Enter 填入假密码。
- 点击用户名框，按 Ctrl + Enter 仅填用户名；按 Shift + Enter 验证用户名、Tab、密码连填。
- 使用中文输入法搜索中文，确认候选词时不会提前填充。
- 上下键选择、无结果和 Esc 取消正常，页面不自动提交。
- 锁定后从目标输入框呼出悬浮框，解锁后仍能填回原目标；超时目标应取消并要求重新定位。

## aTrust

先新建“aTrust 测试”假账号，记录 aTrust 版本与是否以管理员身份运行。

- 点击密码框，呼出悬浮框，按 Enter，仅填入假密码，不点击登录。
- 点击用户名框，按 Ctrl + Enter，仅填用户名。
- 从用户名框按 Shift + Enter，确认 Tab 后密码完整填入；再验证单独填密码。
- 连填等待期间切换窗口，或锁定密码库，密码不得继续发送。
- 如果输入被拒绝，记录现象；不反复发送，不把整个程序提权作为默认解决办法。

## 自动锁定与异常

- 实际按 Win + L 锁屏后返回，确认库已锁定。
- 实际休眠并恢复，确认库已锁定。
- 系统无鼠标和键盘输入约 5 分钟后，确认库已锁定；包含文件对话框打开的情况。
- 在打开备份对话框时锁屏，确认返回后对话框已取消、密码库已锁定。
- 目标窗口关闭、焦点变化、目标超过 60 秒时取消填充。
- 重复启动、快捷键冲突有明确提示。退出后释放快捷键；对话框打开时退出也应完成。
- 验证不同缩放比例、多显示器及真实中文输入法。

## 本版仍未覆盖

已实测 1 分钟密码库无操作超时，包含其他程序持续输入的场景。aTrust 本体、电脑整体空闲超时、真实锁屏/休眠、多显示器与输入法需要人工复测。本机 Windows Hello API 检测不可用，其拒绝与主密码回退已测；真实验证成功路径仍需有可用设备时验收。自动锁屏和休眠用例向本程序发送通知，不会真的锁定或休眠用户电脑。

断电、强制终止、磁盘硬件故障和长期使用尚未完成验证；当前没有 KDBX 导入导出或云同步功能。

## 主密码与本地备份（0.6）

- 在“设置 → 主密码与本地备份”核对数量。确认仅包含自动备份和升级前备份，手动导出副本不计入。
- 检查密码默认掩码、显示切换、确认值不一致、当前主密码错误；返回、Esc 和锁屏后输入应清空。
- 修改后用新主密码解锁并重启，旧主密码应失败；逐个恢复已同步的备份，确认可用新主密码打开且账号内容完整。
- 清除前可取消；错误主密码不能清除。确认清除后当前密码库和手动导出副本仍存在，备份数量归零；再编辑一次账号应重新生成自动备份。
- 仅在隔离测试目录模拟改密中断、文件占用和损坏备份。切换阶段失败时保留 `master-change`，关闭占用程序并重启，恢复后使用新主密码。
- 核对两个外层 exe 一致，仅保留最近 3 个发布版本；密码库不随构建清理。

## 账号菜单、备份列表与启动（0.7）

- 先选中账号 A，再右击账号 B，编辑应打开 B；删除 B 仍需确认，敏感项仍需复验。空白处右击可新增，新增表单不复用旧字段。
- 备份时间、类型、大小、排序正确；上下键切换可见选择，刷新保留有效选择。取消单份删除不删文件，错误密码不删文件；确认后只删除选中备份。
- 恢复错误密码留在列表，正确密码切换独立副本且不用重复输入；原库与备份仍在，重启记住新副本并要求解锁。
- 两项启动设置默认关闭。保存托盘偏好后，手动启动始终显示主界面，带 --autostart 的启动应隐藏且锁定；已运行时再次手动打开会唤起原实例。托盘和原快捷键可打开。测试开机登记时先核对实际 exe 路径，真实登录执行单独验收；移走 exe 后重新保存。
- 在最小尺寸和实际缩放下检查设置页滚动、备份操作密码字段、确认按钮和键盘焦点。

## 拼音搜索与键盘操作（0.8）

- 中文名称可用全拼和首字母搜索，例如企业邮箱 → `youxiang` / `qyyx`；用户名、分类、标签、网址可跨字段组合查询，密码和备注不参与。多音字结果、实际常用简称及英文错拼需要用自己的账号再核对。
- 无搜索词时最近完整成功填充在前；查询时更相关的结果优先。失败、取消、连填中断不改变最近使用，重启仍保留。
- 每次敏感操作默认 Windows 密码，Tab/Shift + Tab 正反循环三种方式；切换清空主密码。实际系统凭据只在 Windows 弹窗中输入。
- 录制原有呼出组合、其他应用已注册的组合、功能键和数字；Esc 和失焦取消。外部组合应能识别且不触发对方程序动作；保存时发生冲突应保留原设置。录制结束后其他程序的快捷键恢复。
- 设置只有一个“保存设置”；保存后快捷键、空闲规则和启动偏好一致，部分写入失败恢复原设置。录制期间不能保存。
- 连续右击不同账号，菜单移动且对应行突出显示；检查列表滚动后、窗口边缘以及实际 DPI 和多屏情况下的位置。菜单方向键/Enter/Esc、敏感操作和删除确认应正常。

## 界面与编辑连续性（0.9）

- 检查建库、解锁、列表、编辑、验证、设置、备份及主密码维护的字体、留白、按钮状态和滚动区域；最小尺寸下操作区保持可见。
- 菜单鼠标移动到编辑、删除和新增时分别高亮，键盘上下与 Enter/Esc 保持可用。
- 悬浮框从多结果切换为单结果应缩小；拼音、首字母和英文错拼高亮原始文字，敏感用户名保持隐藏。
- 保存后对应账号被选中并可见。未保存编辑的取消、Esc、收起和退出需明确选择；继续编辑保留草稿，放弃不改变已保存内容。锁屏仍直接清除草稿。
- 从旧版升级后重新保存开机启动设置，确认 Run 命令含 --autostart；真实登录执行单独验收。

## 紧凑界面与管理跳转（0.10）

- 主窗去除外层灰色留白，缩放和恢复后保持完整绘制。
- 普通账号的用户名始终保留，匹配来源追加；同名不同用户名能够区分。敏感项继续隐藏用户名。
- 拼音与中文命中使用深橙色粗体，选择底色仍清楚，特殊符号显示为原始数据。
- 悬浮框按 Ctrl+Shift+M 打开管理页，原目标取消、没有输入或自动验证；锁定时仍需主密码。
- 在 640×600 和本机 DPI 下检查长名称、多标签、长网址及备注、下拉框、编辑和设置固定操作区。

## 外观、布局与还原（0.12）

- 切换三种外观与四套配色，保存、重启，检查主窗、悬浮框和原生输入；白色桌面上边界清楚。
- 拖动缩放后重启，检查正常位置和尺寸；最大化重启后仍最大化，锁定页不覆盖管理尺寸。真实多显示器拔插及不同 DPI 仍需人工检查。
- 悬浮框应显示应用、窗口/页面标题和位置来源；目标不可用时不填充。
- 仅在隔离测试库执行还原：错误主密码不得改动文件；正确主密码加确认后清除管理数据、全部设置与启动登记，外部导出保持不变。
- 文件占用导致未完成时应明确提示，关闭后释放占用，重新启动完成已授权清除。

## 首版品牌、详情与安装（1.0）

- 检查 Keyisle 英文主品牌、图标、任务栏和托盘；窗控尺寸与线条一致，最大化后显示还原图标，关于页可从锁定页和主菜单进入。
- 在不同应用使用不同账号，空查询应优先本应用最近成功记录；明确搜索时相关性优先。
- 详情默认只读且密码隐藏，非法网址不打开；敏感查看复验，查看授权不能用于编辑；锁定关闭详情。
- 悬浮框失焦后 Esc 仍关闭，不把本次按键传给其他窗口；关闭后外部窗口正常接收新的 Esc；长按和重复不残留钩子。
- 首次安装、Unicode 目录、快捷方式、旧库打开、覆盖升级、运行中阻止覆盖、卸载保留数据、重装继续解锁。
- 实际 GitHub 更新与代码签名属于首次公开发布前的独立验收；当前候选版尚未启用更新服务。
