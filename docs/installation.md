# 安装、升级与卸载

从[最新版下载页](https://github.com/dfx1822375/Keyisle/releases/latest)获取安装包、便携包和校验清单。该入口会自动跳转到最新公开版本。

安装包仅面向 Windows x64。下载 `Keyisle-<版本>-Setup-x64.exe` 后双击，按向导选择目录和快捷方式；默认只安装到当前用户，不要求管理员权限。

程序目录与密码库目录分开。默认程序目录为 `%LOCALAPPDATA%\Programs\Keyisle`，默认用户数据目录沿用 `%LOCALAPPDATA%\PasswordHelper`，所以旧版用户可直接升级。

## 覆盖升级与在线更新

从 1.0.0 升级到 1.1.0 时，请从下载页手动获取安装包或便携 ZIP。1.1.0 起可以在应用内检查并安装后续版本。

Keyisle 支持免手动退出的平滑覆盖升级：

1. **应用内一键升级**：软件默认在启动后后台静默检查更新（可在“设置 → 启动与更新”中关闭），也可随时在“设置 → 启动与更新”选项旁或“关于 Keyisle”中点击“检查更新”。发现经发布者 ECDSA P-256 签名验证的新版本后，点击“下载并覆盖安装”即可完成 SHA-256 校验、自动锁库、原位覆盖安装并重新启动（同时支持安装版与便携版）。
2. **安装包直接覆盖**：无需先从托盘手动退出，直接运行新版 `Keyisle-<版本>-Setup-x64.exe` 时，安装器会自动通知正在运行的实例锁库并平滑退出；若当前存在未保存的账号草稿或正在执行的维护任务，会将窗口切到前台提示处理，绝不强制杀进程。

覆盖升级仅替换程序文件，完整保留账号、主密码、备份和偏好。程序迁移到新目录后，首次启动会同步已启用的本程序开机启动路径，不会替用户开启原本关闭的开机启动。

## 卸载

在 Windows 应用列表中选择 Keyisle 并卸载，或使用开始菜单的“卸载 Keyisle”。卸载只删除本程序的已知文件、快捷方式、安装登记和指向本安装位置的启动项，不递归删除用户添加的未知文件。

账号、主密码、加密备份与偏好会保留；重新安装后可以继续解锁。若需要清空这些内容，请先在程序设置中执行“一键还原”，按提示验证当前库主密码并确认。

## 便携版

解压便携包后运行 `Keyisle.exe`。数据默认仍保存在当前 Windows 用户的数据目录，与安装版共用；请勿同时运行两个实例。源码开发和旧测试入口保留 `windows-password-manager.exe` 名称以兼容已有路径。

## 校验与签名

下载页同时提供安装包、便携包和 `SHA256SUMS`。可用 PowerShell 的 `Get-FileHash` 比对对应文件的 SHA-256。校验清单用于检查文件完整性，不能替代发布者代码签名。

当前安装包尚未附加受信任的 Authenticode 发布者签名，可能显示“未知发布者”或触发 Windows 下载信誉提示。
